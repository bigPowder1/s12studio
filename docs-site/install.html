Install guide

The beta installers are not code-signed yet, so your computer warns you the first time. This page shows what each warning means and what to click. You only do this once.

  • Windows
  • macOS
  • Linux

Windows 10 / 11

  1. Download S12Studio-…-win-x64-setup.exe from the latest release. If your browser says the file "isn't commonly downloaded", choose Keep (Edge: … → Keep → Show more → Keep anyway).
  2. Run the installer. A blue "Windows protected your PC" box (Microsoft Defender SmartScreen) appears because the app is new and unsigned.
  3. Click More info, check that the app is "S12 Studio", then click Run anyway.
  4. The installer sets up S12 Studio for your user account (no administrator password needed; you can change the folder) and adds Start menu and desktop shortcuts. Double-clicking a .mcp project can open it in S12 Studio.

Smart App Control. On some new Windows 11 PCs, Smart App Control is turned on and blocks unsigned apps completely, with no Run anyway button. Check Windows Security → App & browser control → Smart App Control. If it is On, use a lab PC until a signed release is available. (Turning Smart App Control off cannot be undone without reinstalling Windows, so we do not ask you to.)

Updates: on Windows, S12 Studio checks for a new version when it starts and offers Restart to update.

Uninstall: Settings → Apps → Installed apps → S12 Studio → Uninstall. Your projects are not touched.

macOS

Pick the right download: Apple Silicon (arm64) for M1/M2/M3/M4 Macs, Intel (x64) for older Macs. Apple menu → About This Mac tells you which you have.

  1. Open the .dmg (S12Studio-…-mac-arm64.dmg or …-mac-x64.dmg) and drag S12 Studio into Applications.
  2. Open S12 Studio from Applications. macOS says "Apple could not verify “S12 Studio” is free of malware…" (older versions: "can't be opened because it is from an unidentified developer"). Click Done (or OK). Do not move it to the Trash.
  3. Open System Settings → Privacy & Security and scroll down to Security. Next to "S12 Studio was blocked to protect your Mac", click Open Anyway.
  4. Confirm with Open Anyway again and enter your Mac password or use Touch ID. From now on S12 Studio opens normally.

"S12 Studio is damaged and can't be opened"? Make sure you downloaded the build for your Mac's chip. If it still appears, open Terminal and run xattr -dr com.apple.quarantine "/Applications/S12 Studio.app", then open the app again.

Updates: the Mac beta cannot update itself. When a new version is out, S12 Studio tells you and opens the download page; install it the same way (replace the app in Applications).

Real board: the Mac version is simulator only. The lab's P&E pod only has Windows drivers.

Linux

  1. Download the .AppImage.
  2. Make it executable and run it: 
    chmod +x S12Studio-*.AppImage
./S12Studio-*.AppImage
  3. If it does not start, install FUSE 2: Ubuntu 24.04 and later sudo apt install libfuse2t64; Ubuntu 22.04 sudo apt install libfuse2.

First run

Open your lab project: copy the blank_project folder ME 305 gives you (course page) somewhere you can write (building writes bin/ and object files next to the project, as CodeWarrior does), then File → Open… and pick its .mcp. S12 Studio does not include the course library or template; they come with your course's project folder. Then follow the quick start: F7 to build, F5 to debug (the ME305 Board opens on the right), F5 to run.

No course project yet? Open the demo project (Help → Open Demo Project, or from the startup dialog), or File → New Project… for an empty assembly project (without the ME 305 library).

Problems? Open an issue with your OS and what you saw.
